# GSimp (vendored source)

This directory contains a snapshot of the GSimp imputation source files used by
the YvO 2026 imputation benchmark.

- **Upstream:** https://github.com/WandeRum/GSimp
- **License:** GNU General Public License v3 (see `LICENSE` in this directory)
- **Citation:** Wei et al. 2018, *PLOS Computational Biology* 14:e1005973
- **Wrapper:** `02_Imputation/a_script/benchmark/methods/09_gsimp.R` (sets
  `GSIMP_DIR` and sources `GSimp.R` here).

The files are imported verbatim from upstream. Do not edit the contents of
this directory; modifications belong in the wrapper script.
